## How it works

`main.py` (Python standard library only, no network) holds the apology as a
single string, normalises its whitespace, enforces the competition gate
(1–200 characters, a single non-blank line), and writes it to
`/output/entry.txt` with no trailing newline.

Run it with:

```sh
python3 main.py
```
